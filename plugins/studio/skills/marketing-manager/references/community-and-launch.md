# Community, influencers, PR and launch

## Community channels
| Channel | Role | Cadence (practitioner) | Rules |
|---|---|---|---|
| Discord | core fans, playtests, feedback, LFG | daily presence; weekly announcement | channels: announcements, rules, roles, feedback, bugs, LFG, off-topic; AutoMod + human mods; publish rules + escalation |
| Reddit | own subreddit + genre subs | weekly own-sub post; genre subs only when valuable | follow each sub's self-promo rules; reply as devs with flair; never astroturf |
| TikTok / Shorts / Reels | reach, devlog, gameplay moments | 3-5 posts/week during build-up | hook in 1-2 s; native vertical; trends adapted to the game |
| YouTube | trailers, devlogs, patch videos | per milestone + monthly devlog | chapters, captions, end screens to store page |
| X / Bluesky | press, industry, dev community | several/week | GIFs of gameplay (#screenshotsaturday-style) |
| Steam Community / events | wishlisters, owners | every update + events | Steam events/announcements surface to followers and wishlisters |
- KPIs: joins → weekly active members, messages/day, sentiment, feedback items triaged/week,
  UGC count, traffic and wishlists/installs from community links (UTM).
- Feedback loop: weekly digest (top 5 themes with counts) → product-manager / lead-game-designer.
- Moderation & safety: code of conduct, minors policy, harassment escalation, ban appeal path.

## Influencer / streamer program
| Tier | Followers | Typical use |
|---|---|---|
| Nano / micro | < 10k / 10k-100k | authentic niche reach, key-only deals, high engagement |
| Mid | 100k-500k | paid integrations for launch beats |
| Macro / mega | 500k+ | launch day / big reveal, expensive, brand reach |
- Discovery and keys: Keymailer, Lurkit, Woovit-style key platforms; viewership data from
  Streams Charts / TwitchTracker (verify tool availability).
- Brief: must-show, must-not (spoilers, unreleased content), talking points, embargo date/time,
  tracked link/code, disclosure requirement, payment terms, content rights.
- Measure: views/CCV, watch time, CTR on tracked links, wishlists/installs, cost per
  wishlist/install, sentiment; compare against paid UA CPI.
- Disclosure (mandatory in every contract):
  - US FTC Endorsement Guides (2023 revision): disclose any material connection (payment,
    free keys/gifts, affiliate links) clearly and conspicuously, in the same format as the
    endorsement (spoken in streams/videos, not only in descriptions); tags alone are not
    enough; liability extends to advertisers and intermediaries (agencies, MCNs). The first FTC
    action against individual influencers (CS:GO Lotto, 2017) was gaming-related.
  - FTC rule on fake reviews and testimonials (2024): no buying or faking reviews (verify scope).
  - UK CMA/ASA influencer guidance (updated 2025): "Ad"/"Advert" label up front; gifts, trips
    and commission count as payment; CMA can fine directly under the DMCC Act (up to 10% of
    global turnover); ASA names non-compliant influencers.
  - Use platform tools too: YouTube "includes paid promotion", TikTok content disclosure,
    Instagram "Paid partnership", Twitch branded content tools (verify each platform's rule).
- Never pay for review scores, require positive coverage, or ask for store reviews in exchange
  for keys (store policies + consumer law). Social casino/gambling-adjacent influencer content
  has extra restrictions (age-gating, no win claims) → compliance-advisor.

## PR and press kit
- Press kit (web page + zip): fact sheet (name, developer/publisher, release date, platforms,
  price, languages, website, socials), short (50 words) and long (200 words) description, key
  features, 6-10 screenshots, trailer (download + YouTube), logos (transparent PNG/SVG), key art,
  capsule art, team bio/photo, awards/quotes, press contact. presskit()-style layout is the norm.
- Outreach: target list by outlet/creator relevance; previews 4-6 weeks before launch; review
  codes 1-2 weeks before with embargo; personal pitch (3-4 sentences + link + key offer).
- Distribution: games press-release services (e.g. GamesPress) + direct emails; local-language
  outlets for top geos.
- Track coverage: outlet, date, reach, sentiment, link → `.team/reports/marketing/coverage-<date>.md`.

## Launch timeline (T-minus; adapt per platform)
| When | Steam / PC / console | Mobile F2P |
|---|---|---|
| T-12 to T-6 mo | Steam page live, announce trailer, Discord open, wishlist drive | soft-launch plan, creative concept tests |
| T-6 to T-3 mo | demo/playtest, Next Fest, festival circuit, influencer seeding | soft launch (gates in domain skill), ASO baseline |
| T-3 mo | release date announce; press previews; featuring/platform pitch | pre-registration/pre-order (Apple pre-orders up to 180 days ahead - verify); Apple featuring nomination |
| T-6 wk | review-code plan, trailer 2, influencer contracts signed | UA creatives ready, CPPs/custom listings, store experiments concluded |
| T-2 wk | Coming Soon >= 2 wk (Steam minimum), final build, review codes out | In-App Event/promo content submitted; launch event content (liveops) |
| T-1 wk | press release final, stream schedule, community AMA | UA campaigns built and paused, MMP/SKAN verified end to end |
| T0 | launch trailer, PR, socials, influencer go-live, war room | UA burst per plan, war room (crash, CPI, ratings, ranks) |
| T+1 d to T+30 d | review responses, hotfixes, first update roadmap, post-launch sale plan | reallocate by cohort ROAS, review responses, first event beat |
- Every external action (publishing, store submission, paid spend, press release) needs human
  approval (team-protocol).
- Date choice: avoid big AAA launches in your genre, platform sales (December/Winter Sale
  converts worst on Steam), major holidays for your top geos; check SteamDB upcoming lists.

## Crisis communications
| Trigger | First response |
|---|---|
| Outage / broken launch | holding statement <= 1 h; status updates on a fixed cadence |
| Exploit / economy incident | coordinate with liveops-manager playbook; no blame on players |
| Controversial change (monetization, pricing, nerf) | explain why + what changes; listen period; avoid defensive tone |
| Review bombing | stay factual; Steam marks off-topic review bombs (Valve detection since 2019) |
| Data breach / security | legal + security-engineer + compliance-advisor before any statement |
| Partner/influencer scandal | pause campaign; statement aligned with legal |
- Protocol: monitor → assess severity → single owner + approver → holding statement → facts
  → actions + timeline → follow-up when resolved. Same message on all channels, timestamped.
- Never: delete criticism (except rule-breaking), speculate on causes, promise what isn't approved.
